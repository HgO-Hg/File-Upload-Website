# 文件中转站（File Upload Website）

一个**无验证, 无登录**的临时文件中转网站：把文件拖进网页 → 生成一条下载直链 → 把链接发到另一台设备打开即可取件.

本网站为实验性项目,无法保证网站的稳定性.如果因使用本网站而造成任何泄密或损失站主概不负责.

由Deepseek-V41-Flash辅助生成.

---

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 拖拽 / 点击 / 粘贴上传 | 支持拖入、点击选择、多选，以及直接 `Ctrl+V` 粘贴截图 |
| 文件队列 | 最多 200 个文件排队，逐条显示进度、成功or失败状态 |
| 大文件分片上传 | 超过阈值的文件自动切分为多片上传后合并 |
| 断点续传 | 上传会话缓存在 `localStorage`，刷新或换浏览器后可从已传分片继续 |
| 取消上传 | 可中断正在进行的请求（基于 XHR abort） |
| 保存时长 | 1 小时 / 6 小时 / 1 天 / 7 天 / 30 天 / 永久 |
| 分区 | 给文件打一个分区标签，同区可见 |
| 下载 | 按取件码刷新列表，或直接粘贴下载直链打开 |
| 安全 | 网站无法保证任何存储在其中的文件的安全性.请谨慎下载.如果要传递敏感资料或者你不希望其他人得到文件,请勿使用 |

## 重要限制与注意事项

**分片过多会在合并阶段失败** 合并请求每个分片要消耗 2 次 R2 操作，免费额度为单次调用 1000。前端把安全片数控制在 400 片以内，超出会提示你把分片调大.

**安全提醒** “无验证上传”意味着任何拿到网址的人都能上传和下载。建议在服务端设置体积上限与保存时长并定期清理；涉密或私人文件不要走这条链路.

**上传中别刷新** 队列与进度保存在内存中，刷新即丢失；页面会在离开时弹出确认提示。单次请求超时保护为 20 分钟.

**文件上限** 单次传输文件上限为5GB,过多会导致传输失败.全体用户存放文件总和限制为10GB.如果有因空间不足导致的上传失败请联系站主清理非必须文件.

**保存时长** 请尽量选择较短的保存时长.如果需要长期保存文件请联系站主.如果有任何未经允许而上传的永久文件会被站主手动清理.我们的存储空间不大,无法支撑如此消耗.
